# The Strategic Capital Order

**Finance, Technology, and the New Global Hierarchy**

Book proposal package for Edward Elgar Publishing.

## Structure

- `proposal/` — English-language proposal documents
- `proposal_pl/` — Polish-language parallel version
- `proposal_compiled/` — Final assembled proposal (EE form + cover letter)
- `source_materials/` — Original concept and references

## Core Argument

This monograph introduces **Capital Allocation Capacity (CAC)** as a new analytical framework arguing that the ability to mobilize, structure, and direct capital into strategic technology value chains — not technology ownership per se — has become the primary determinant of position in the emerging global hierarchy.
